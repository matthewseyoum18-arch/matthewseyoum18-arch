# Matthew Seyoum

Founder-engineer. I build products end to end and sell them myself.

## What I've shipped

**Parkey** - a two-sided gameday parking marketplace, live on the App Store.
Hosts list their driveways near stadiums; fans book them. React + Capacitor,
Postgres, Stripe payments and host payouts. I co-founded it and build across
the stack.
[Download on the App Store](https://apps.apple.com/us/app/parkey/id6761501532)

**MondayBrief** - a GTM workflow system that turns public city signals
(licenses, permits) into scored weekly sales briefs for local B2B service
companies. Python, LLM scoring with review gates, golden-label evals.
[Repo here](https://github.com/matthewseyoum18-arch/mondaybrief)

**AI outreach platform + agent pipeline** (private) - the systems behind my own
outbound sales: account scoring against an ICP, personalized sequences, and a
cron pipeline of LLM agents on a Linux VPS that sources leads and reports over
Telegram. Ask me about them.
